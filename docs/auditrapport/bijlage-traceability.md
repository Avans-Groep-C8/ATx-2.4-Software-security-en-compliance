## 3. Conclusie

Deze matrix ondersteunt de WS06-eis voor traceability: elke rij koppelt een specifieke NEN 7510-2-control aan een maatregel, een concrete nulmeting, een wijziging en een verifieerbaar bewijsartefact. De belangrijkste gerealiseerde verbeteringen zijn toegangscontrole op kritieke endpoints, afscherming van configuratie, RBAC op system settings, audit logging voor patient-write-acties en aantoonbare CI/SCA/SBOM-controls.
